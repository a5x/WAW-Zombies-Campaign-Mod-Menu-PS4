# Installation

### Step 1

Install **01cedric COD Updater** and the required **COD files**.

### Step 2

Drag and drop the `WAW_ZM_MAG` files into your **WAW mods folder**.

### Step 3

Launch WAW in Multiplayer go in mods option, enable WAW ZM MAG and back in main menu and go in **Zombies** or **Campaign** to use the menu.
